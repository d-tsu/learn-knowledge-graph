# mdBook・GitHub Pagesの構築と表示確認

実施日：2026-10-20。担当：Codex。本件はWeb配信の追加であり、本文の定義・例・演習・学習順序を改稿する作業ではない。章の新規執筆・大幅改訂に対する独立レビューは対象外。セルフレビューとサイトの動作確認を行った。

## 対象と構成

`book.toml`、`site/`、`scripts/build-book.py`、`scripts/check-book.py`、`scripts/check-book-browser.cjs`、`.github/workflows/book.yml` と、README・管理文書の案内を対象とする。

正本の本文18ファイル・付録6ファイルを含む31ページをmdBookで生成する。目次はOUTLINEの5部構成に合わせた。公開対象をSUMMARYで指定し、対象外文書や実習コードへのリンクはGitHubへ向ける。生成物・ツール・ローカルの証跡はtmp配下で管理し、PDFは生成しない。

## 確認結果

| 確認 | 結果と範囲 |
|---|---|
| ツール | mdBook 0.5.4、mdbook-mermaid 0.17.1、Python 3.12系。Mermaid本体は固定した拡張の同梱版を使用 |
| ビルド | Windowsで31読書ページの生成に成功。拡張のmdBookビルド版との差に関する警告あり。描画結果は別途確認 |
| 内部リンク | 生成した33 HTMLページの内部リンク・アセット1,161件を確認。目次・404ページを含む。検索索引内の各見出しへのリンクも確認 |
| 公開対象 | 生成物にMarkdown・PDF・実行ファイル・Pythonコード・旧草稿・レビュー証跡・Gitの内部ファイルが含まれないことを検査 |
| ブラウザー | Edgeヘッドレス、デスクトップ1365×950とスマホ相当390×844で確認 |
| 図 | 31読書ページを巡回し、29図すべてのSVG描画を確認。明暗テーマ切替後の描画、代表図と本文のスクリーンショットを目視確認 |
| 検索 | 標準検索では日本語の結果を得られなかったため、生成HTMLに対する日本語部分一致検索を追加。オントロジー、借り手、トレーサビリティ、SHACL、複数語、該当なし、結果から見出しへの遷移、/とEscapeを確認 |
| スマホ相当 | 本文の横はみ出しなし。目次の開閉と章への遷移を確認。大きな図・表は要素内の横スクロールで読む |

ブラウザー検査の詳細は `tmp/book-browser/report.json` と同フォルダーの画像に保存する。再現手順は[Web版の管理](../site/README.md)を参照。ローカルの証跡は公開サイトへコピーしない。
