## ファイルの役割

案内と章別ブランチの運用については[main合流前の点検](2026-10-07-main-integration.md)に記録した。

| 名前・場所 | 内容 |
|---|---|
| `YYYY-MM-DD-対象名.md` | 執筆・セルフレビュー・指摘対応・最終状態 |
| `YYYY-MM-DD-対象名-independent.md` | 独立レビュアーの初回報告と再確認 |
| `YYYY-MM-DD-対象名-publication-check.md` | 共有前の変更範囲、情報混入、リンクなどの点検 |
| [assets/](assets/) | 対象ハッシュ、Markdown検査、MermaidのSVG・PNGなどの証跡 |

本文のレビュー、図の描画、実行確認、実読者による理解確認は別の確認である。実施した範囲と未確認事項は個々の報告を読む。旧草稿や応用題材全体、実製品の導入効果をすべて確認済みとする一覧ではない。
