## 再利用するためのひな形

- [設計知識レコード](templates/knowledge-record.md)：設計書にIDがない場合も、抽出した主張にID・根拠・状態を付ける。

各章の「復習」と「演習」を学習のチェックポイントにします。図はMermaidです。表示にはMermaid対応のMarkdownビューアが必要です。

## この版の範囲

2026-09-26作成。公式仕様・提供元資料の確認に基づく学習用初版です。業務への適用方法と架空のテスト例は本資料の提案であり、実製品で効果を検証した結果ではありません。実行用DBやツールは導入していません。
