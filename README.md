# AIエージェント開発のためのナレッジグラフ・オントロジー学習ノート

設計書・開発ルール・コード・テストの関係を明示し、AIエージェントが根拠をたどって開発できるようにするための学習資料です。まず理論と方法を学び、次に技術比較、小規模な実証へ進みます。

## 今後の執筆構成

[改訂目次・執筆方針](OUTLINE.md)を今後の作業の基準とします。序章・5部17章・付録の構成で、外部レビューの検討とユーザー合意を反映しています。

別PC・別のタスクで再開するときは、[作業引き継ぎ](HANDOFF.md)も確認してください。

以下の資料は目次合意前に作成した初期草稿です。改訂目次への再編・不足部分の執筆は未実施です。

## この版の範囲

2026-09-26作成。公式仕様・提供元資料の確認に基づく学習用初版です。業務への適用方法と架空のテスト例は本資料の提案であり、実製品で効果を検証した結果ではありません。実行用DBやツールは導入していません。

TrikeDBはユーザーの方針により調査・比較対象から除外。TypeDBへの読み替えもしません。Graphifyは指定された graphify.net を起点とします。

概観用スライドは後続成果物です。現時点では未作成。各章の復習項目と題材別の事例をスライドの材料にし、詳細資料を正本として対応を維持します。
