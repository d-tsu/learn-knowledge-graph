# 用語集

本資料の読み方をそろえるための短い定義。標準の厳密な定義や製品機能は[参照資料](08-sources.md)を確認する。

| 用語 | 意味 |
|---|---|
| ノード / エッジ | 対象 / 対象間の関係 |
| 経路 / 探索 | 関係の連なり / それをたどる処理 |
| ナレッジグラフ | 対象と意味付きの関係を結び、利用可能にした知識 |
| オントロジー | 概念・関係・意味上の公理の定義 |
| タクソノミー | 分類の階層 |
| クラス / 個体 | 対象の種類 / 具体的な対象 |
| スキーマ | データ構造の定義。文脈により意味モデルも含む |
| プロパティグラフ | ノード・関係に属性を持たせるグラフモデル |
| RDF / トリプル | 主語・述語・目的語を使うデータモデル / 一つの記述 |
| IRI | 対象や語彙を識別する国際化資源識別子 |
| Turtle | RDFのテキスト記述形式 |
| RDFS | RDFのクラス・プロパティ等を記述する語彙 |
| OWL | オントロジーの意味・公理を形式的に記述する言語 |
| SHACL | RDFデータへの制約を記述・検証する仕様 |
| SPARQL | RDFの問い合わせ言語 |
| Cypher / Gremlin | グラフへの問い合わせ・探索に使う言語 |
| 推論 | 事実と規則・公理から帰結を導くこと |
| 開世界仮定 | 記述がないことを偽と決めない考え方 |
| 閉世界仮定 | 定めた範囲で、成立が確認できないものを偽と扱う考え方 |
| Provenance | 情報の由来、作成・導出の経緯 |
| エンティティ解決 | 異なる表記が同じ対象かどうかを照合する処理 |
| コンピテンシー・クエスチョン | モデルが答えられるべき問い |
| トレーサビリティ | 要件・設計・実装・テストなどの対応を追跡できること |
| RAG / GraphRAG | 検索情報を使う生成 / その検索にグラフを使う方式 |
| MCP | AIアプリと外部ツール・リソースを接続するプロトコル |
| AST | ソースコードの構文を木構造にした表現 |
| テストオラクル | 期待結果や正否を判断する根拠・仕組み |
| Fixture | テストのために用意するデータや環境状態 |
| RBAC | ロールを介して権限を管理する方式 |
| ABAC | 主体・資源・環境等の属性を使うアクセス制御方式 |

「推論」はLLMによる自然言語上の推測と、形式的な規則による導出を区別して使う。「検証」はデータの形の検証と、業務的な正しさの検証を区別する。
