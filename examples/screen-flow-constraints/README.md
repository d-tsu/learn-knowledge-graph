# 画面フローの条件計算

[第15章](../../docs/chapters/15-integration-testing.md)の追加教材設定を計算する。元の題材の未定義仕様を決めるものではない。

Python 3.12で、リポジトリのルートから次を実行する。外部ライブラリは不要。

```powershell
python examples/screen-flow-constraints/verify.py
```

`status: passed` と、選択レコードP-01・P-02、利用可能額70、四つの境界例を出力する。D-02の申請と処理済み申請を除外した集計、Cのエラー入力80件、特別のままCへ進む入力0件、P-02変更後の利用可能額50も確認する。

`requests.json`の`pending`は未処理、`processed`は処理済みを表す。金額はすべて円。TU-01はD-01に属し、アクセス条件を満たすものとする。計算中に準備レコードは変わらない。

プログラムは分岐と金額規則だけを評価する。実際のログイン・画面・API・DBへは接続せず、登録処理やエラーメッセージも実装しない。権限やエラー時に登録しないことの動作確認は、実システムで別途行う。
